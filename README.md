# 📈 쌈지 (SSAMJI)

> 투자도 경제도, 쌈지에 담다

중·고등학생을 위한 **모의투자·경제 학습 웹앱**. 설치·회원가입 없이 브라우저만 있으면 바로 시작합니다.
기술·가정 「자원 관리와 소비」, 사회 「경제」 단원 수업에 쓰려고 만들었습니다.

**라이브**: https://ssamji.samluv.workers.dev

---

## 무엇을 하는 앱인가

학생은 가상의 **1,000만 원**으로 국내 30개 기업에 투자하며, 매매할 때마다 **「왜 샀는지」 근거를 문장으로 남깁니다.**
시뮬레이션 시계를 배속으로 돌려 몇 달치 등락을 압축해서 겪고, 그 결과를 거래일지로 되돌아봅니다.

이 앱의 목표는 수익률을 올리는 요령이 아니라 **자기 판단의 근거를 세우고 점검하는 경험**입니다.

## 주요 기능

| 탭 | 내용 |
|---|---|
| 📈 시장 | 국내 30개 기업. 각 기업에 **「만드는 물건」**이 적혀 있어 학생이 아는 제품에서 회사로 이어집니다 |
| 💼 내 포트폴리오 | 보유 종목·평균 단가·평가손익·업종별 비중 |
| 📓 거래일지 | 모든 매매와 **작성한 근거**가 남습니다 (수업 평가 자료로 활용) |
| 🎓 경제 학습 | 경제 개념 카드 8종 + 미션 배지 7종 |
| 🏆 학급 랭킹 | 학급 코드로 참가한 친구들과 수익률·경과일 비교 |

- **시뮬 시계** — 2021년부터의 가상 주가를 1x~30x 배속으로 진행 (▶ ⏸ ⏭)
- **수수료 0.015% · 거래세 0.18%** 반영 → 잦은 매매의 비용을 체감
- **AI 3종** (선택) — 종목 분석 / 매매 코치 / 학습일지 자동 생성

> ⚠️ 주가는 **학습용 가상 데이터**입니다. 실제 기업의 주가가 아니며 투자 권유가 아닙니다.

## 선생님을 위한 안내

### 시드머니는 나눠 주지 않아도 됩니다
학생이 접속하는 순간 **자동으로 1,000만 원**이 지급됩니다. 전원 같은 금액이라 비교가 공정합니다.

### 로그인이 없습니다
아이디·비밀번호를 만들지 않습니다. 주소만 열면 바로 시작합니다.

### 학생을 미리 등록하지 않아도 됩니다
1. 선생님이 `🏆 학급 랭킹` → `🏫 학급 참가하기` → **학급 만들기**로 **6자리 코드**를 발급받습니다
2. 코드를 칠판에 적어 주면, 학생이 **별명 + 코드**를 넣고 스스로 참가합니다

학급에 참가하지 않아도(`개인 모드로 계속하기`) 랭킹만 빠지고 나머지 기능은 그대로 작동합니다.

### 차시 간 이어서 하기
보유 종목·현금·거래 근거·**시뮬레이션 날짜**까지 모두 저장되어, 다음 시간에 **멈춘 지점에서 이어집니다.**

단, 데이터는 **그 기기의 브라우저**에 저장됩니다. 따라서 —

- ✅ 학생이 **같은 기기**로 돌아오면 그대로 이어집니다 (좌석·기기 고정 권장)
- ❌ 다른 기기 / 시크릿(InPrivate) 모드 / 로그아웃 시 데이터를 지우는 정책이면 초기화됩니다

**크롬북**을 쓴다면 기기가 아니라 **로그인한 구글 계정**이 저장 단위입니다.
학생마다 자기 계정으로 로그인한다면 한 크롬북을 여러 반이 써도 섞이지 않습니다.
다만 관리자가 **임시 모드(Ephemeral)** 를 켜 두었다면 로그아웃마다 초기화되니,
`chrome://policy`에서 `DeviceEphemeralUsersEnabled` 값을 확인해 보세요.

> **1분 확인법** — 학생용 기기에서 아무 종목이나 1주 사고, 로그아웃했다 다시 로그인해 보세요.
> 그 종목이 남아 있으면 여러 차시에 걸쳐 안심하고 이어서 쓸 수 있습니다.

### AI 기능
AI는 **개인 API 키를 넣어야만** 작동합니다(기본값 꺼짐). 키는 각 기기의 브라우저에만 저장됩니다.

학생 기기마다 선생님 키를 넣는 것은 권하지 않습니다(키 노출·요금 문제).
**교사 PC 한 대에만 키를 넣고 화면으로 함께 보는 방식**을 권합니다.
AI를 쓰지 않아도 투자·거래일지·랭킹·개념 카드는 모두 정상 작동합니다.

## 기술 구성

- 빌드 도구 없는 **순수 HTML + CSS + Vanilla JS**
- **Cloudflare Workers** 정적 에셋 배포
- **Firebase**(익명 인증 + Firestore) — 학급 랭킹에만 사용
- 학습 데이터(포트폴리오·시계·설정)는 **localStorage**에 저장, Firestore에는 랭킹 요약만 전송

```
js/
├── data.js       30종목 메타 + 개념 카드 + 미션
├── prices.js     시드 기반 가상 주가 생성
├── clock.js      시뮬레이션 시계
├── portfolio.js  매수·매도·수수료·거래세
├── group.js      학급 코드 생성·참가
├── ranking.js    실시간 랭킹 구독
├── ai.js         종목 분석 · 매매 코치 · 학습일지
└── app.js        전체 UI
```
